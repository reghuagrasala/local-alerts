# Local Alerts V5

- Home shows title/location/GPS/Data controls only.
- Alerts and Report to pages hide the Home title/location/GPS/Data area and use the full available screen for their scrollable content.
- Alerts is a full scrollable newest-first list.
- Report to is a full scrollable device-contact list with Import Contacts at top right and a Back button.
- No sample contacts or user contacts are stored in GitHub.
- Empty states are intentional for verification.
- Gradient background is used around tabs/content for easier viewing.
- A website/PWA cannot physically switch a phone's GPS or mobile-data hardware off; the buttons report/check status instead.
