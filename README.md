# Local Alerts V4

Independent public-help resource.

- No sample contacts are stored in GitHub.
- User contacts are device-only.
- Alerts data is intentionally empty for verification.
- Home shows current date/time, then Active Alerts, Previous Alerts, and grey Inactive Alerts.
- Alerts opens a full scrollable page sorted newest-first.
- Report to opens a full scrollable device-contact page with Import Contacts at top right.
- Back button is available on Alerts and Report to.
- GPS requests a fresh high-accuracy position and displays coordinates alongside the reverse-geocoded address.
- Data status checks the app data resource and online state.
- PWA manifest, service worker and icons are included.

Note: a web app cannot physically switch the phone's GPS or mobile-data hardware off. The GPS/Data buttons report status or initiate a re-check; they do not falsely claim to disable phone hardware.

This is not a Kerala Government website or government service.
