# Local Alerts V3

Independent public-help resource. No user contact data is stored in GitHub.

Features: working GPS request, GPS coordinates shown with reverse-geocoded address, data status test, full Alerts page with Active/Expired/Inactive tabs, full Report to page with All/Active/Inactive contact tabs, Back button, device-local contact storage, Call/SMS/WhatsApp/Email/Website per contact, PWA manifest, service worker, PNG app icons and social-sharing image.

For GitHub Pages, enable Settings → Pages → main → root.

This is not a Kerala Government website or government service.
